    PermissionStatusWhat it means

    Optional OCR

    Recognize the current page only when you ask. Cambuz renders that page locally and sends the image to a separately installed Tesseract engine on this computer. Nothing is uploaded, and no page is OCR’d automatically. Results stay in a separate OCR text box; they are not embedded in the PDF or added to normal document search.

    Install the optional engine and language data separately. Only installed language packs can be selected.

    OCR can make mistakes, especially on low-resolution, skewed, handwritten or mixed-script pages. Review the result before using it.
